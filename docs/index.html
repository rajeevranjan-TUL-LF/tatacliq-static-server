🔗 Quick Start

Fetch JSON data from JavaScript:

fetch('https://rajeevranjan-TUL-LF.github.io/tatacliq-static-server/data/sample.json') .then(response => response.json()) .then(data => console.log(data))

📋 Available Endpoints

  • /data/sample.json - Sample data file
  • /data/ - Browse all data files

💻 How to Add Your Data

  1. Clone: git clone https://github.com/rajeevranjan-TUL-LF/tatacliq-static-server.git
  2. Add files: Copy JSON files to docs/data/
  3. Push: git add . && git commit -m "Add JSON data" && git push origin main
  4. Done: Files will automatically deploy
